# Tic Tac Toe

A simple Tic Tac Toe game built with HTML, CSS, and JavaScript.

## Features

- **2 Players mode** — play with a friend on the same device
- **Vs Computer mode** — play against the computer (it tries to win and block you)
- Scoreboard for X, O, and draws
- Winning line highlight
- Restart round and reset scores

## How to play

Open `index.html` in any browser — no setup needed. Or play it on GitHub Pages.

Players take turns placing X and O. The first to get 3 in a row (horizontal, vertical, or diagonal) wins.
